# E-Commerce & Invoice Dashboard (Frontend)

A modern React frontend for an e-commerce and invoice management system.

## Features
• User Authentication (Login / Register).
• Smart Role-Based UI: Regular emails access standard shopping pages, while emails ending in `@hm` unlock **Accounting** and **Manage Invoices** pages.
• Product catalog (Men, Women, and Product Details).
• Cart and Checkout workflow.

## Technologies Used
• React.js
• React Router
• Context API
• CSS3
